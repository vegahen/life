# My Stance on Free and Open-Source

```yaml
type: source
url: https://en.wikipedia.org/wiki/Free_and_open-source_software
```

Free and open-source software is going to save the world.

If you have never tried it before, it can sometimes be a bit difficult because you need to think for yourself how to install it. Basically the opposite of what the [late-stage capitalists](/psychology/stances/late-stage-capitalism.md) want you to do. Sometimes you even need to use the [command line](https://en.wikipedia.org/wiki/Command-line_interface) to use it.

But that is actually pretty cool, because you'll feel like a hacker. And nowadays learning stuff like that is easy, because there are plenty of free AI chatbots everywhere that you can ask for help!

Let's build a better digital future together!
