# My Stance on Free and Open-Source


Free and open-source software is going to save the world.

If you have never tried it before, it can be a bit difficult at first. Sometimes you need to think for yourself how to install and use it, basically the [opposite](/services/personal/-/openai/openai.md) of what the [late-stage capitalists](/psychology/stances/late-stage-capitalism.md) want you to do. And sometimes you even need to use the [command line](https://en.wikipedia.org/wiki/Command-line_interface).

But all of this is actually pretty cool, because you'll learn how to be independent and think for yourself - you may even get to feel like a hacker in the movies. And nowadays learning stuff like this is super easy, because there are plenty of free AI chatbots everywhere that you can ask for help - I wonder how those get paid.

Let's build a better digital future together.
